# autostar

Сайт СТО AutoStar (Астана). Статика: HTML + один небольшой скрипт, без сборки и зависимостей.
Деплой — Git в PS Cloud (Plesk): содержимое репозитория попадает в `httpdocs` как есть.

## Структура

```
index.html      русская версия  → autostar.kz/
kz/index.html   казахская       → autostar.kz/kz/
en/index.html   английская      → autostar.kz/en/
assets/site.js  меню, модалка, формы, анимации появления
img/            фотографии и карта
fonts/          Oswald и Barlow (локально, без Google Fonts)
favicon.svg, robots.txt, sitemap.xml
```

## Как править

**Тексты** лежат прямо в разметке — открыть нужный `index.html` и отредактировать.
Правку надо повторить в каждой языковой версии: это три независимых файла.

**Телефон** встречается в разметке и в `assets/site.js` (переменная `AS.wa` в `<head>`
каждой страницы — номер для ссылки на WhatsApp).

**Фотографии** — заменить файл в `img/` под тем же именем.

**Версия** показана в подвале (`v1.0.1`) — по ней видно, доехал ли деплой.
При каждом обновлении сайта поднимать номер во всех трёх страницах:

```bash
grep -rn 'data-version' index.html kz/index.html en/index.html
```

## Важно

Контент обязан оставаться в разметке, а не подставляться скриптом. Робот Google Ads
и Safari до iOS 16.4 не выполняют сложный JS — предыдущая версия сайта была собрана
в один самораспаковывающийся файл на 1.9 МБ и у части посетителей не открывалась вовсе,
из-за чего реклама получила отказ «Неработающий целевой URL».

Скрипт `assets/site.js` добавляет только поведение. Если он не загрузится, страница
остаётся полностью читаемой.
